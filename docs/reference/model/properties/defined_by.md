# defined_by

[← all properties](index.md)

## Description

Determines which Enterprise has defined the CustomerCategory

## Definition

- **Predicate**: `dfc-b:definedBy`
- **Range**: `Organization` (a DFC class)
- **Target type**: [`Organization`](../classes/Organization.md)
- **Inverse**: `defines`
- **Cardinality**: **Single-valued on `CustomerCategory`** — the ontology restricts those classes to exactly one value. On that class the property is a scalar; elsewhere it may be a collection, because the ontology is silent.

[`CustomerCategory`](../classes/CustomerCategory.md)

## Available on (1)

[`CustomerCategory`](../classes/CustomerCategory.md)

## Notes

- Declared on 1 class(es) in the ontology, but inherited by 1. The connectors place a slot on every root class when its domain names no schema class, so it is available everywhere.
- The schema records no `required` or `multivalued` flag for this slot.
