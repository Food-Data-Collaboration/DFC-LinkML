# best_before_date

[← all properties](index.md)

## Description

" à consommer de préférence avant le… " : après cette date, le produit peut perdre une partie ou la totalité de ses qualités sans présenter un danger pour la santé : par exemple le café peut perdre son arôme.

- **Predicate**: `dfc-b:bestBeforeDate`
- **Range**: `date` (literal)
