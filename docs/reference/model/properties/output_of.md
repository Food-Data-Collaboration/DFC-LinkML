# output_of

[← all properties](index.md)

## Description

The transformation the produced product is outputed from

## Definition

- **Predicate**: `dfc-b:outputOf`
- **Range**: `string` (literal)
- **Inverse**: `has_output`
- **Cardinality**: **Single-valued on `ProductionFlow`** — the ontology restricts those classes to exactly one value. On that class the property is a scalar; elsewhere it may be a collection, because the ontology is silent.

## Notes

- Declared on 1 class(es) in the ontology, but inherited by 4. The connectors place a slot on every root class when its domain names no schema class, so it is available everywhere.
- The schema records no `required` or `multivalued` flag for this slot.
