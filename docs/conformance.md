## What this does not cover

Conformance is a floor, not a ceiling. Passing every cell means a document survives a round trip through that connector — it does not mean the document is valid DFC. See [validation](concepts/validation.md) for the four levels of validity and which one this is, and [cardinality](concepts/cardinality.md) for the constraint data the connectors carry.

`tests/conformance/invalid/` is a placeholder for negative fixtures. It is empty, so **no connector is asserted to reject anything yet**.
